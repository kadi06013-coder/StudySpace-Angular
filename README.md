# StudySpace – Student Management System

A student management dashboard built with Angular.

## Features
- Add, edit and delete students
- Search students by name
- Form validation
- Toast notifications
- Delete confirmation
- Data persistence using LocalStorage
- Responsive Lavender UI

## Technologies
- Angular
- TypeScript
- HTML5
- CSS3
- LocalStorage

## Installation

```bash
npm install
ng serve
```

Open `http://localhost:4200/` in your browser.
